# Contributing to GhostLab

Thank you for helping extend this open research repository.

## Good Contributions

- Add reproducible analysis scripts or notebooks.
- Improve the codebook or data dictionary.
- Propose corrections to coded cases with clear evidence.
- Add robustness checks, alternative models, or clearer visualizations.
- Report ambiguity in variables, coding definitions, or interpretation.

## Data Standards

- Preserve original case identifiers when possible.
- Do not add private personal information.
- Document any new variable with its definition, allowed values, and coding rule.
- Separate raw/source notes from derived analysis fields.
- State whether a contribution changes the dataset, the analysis, or only documentation.

## Interpretation Standards

This project studies televised narratives as a media-content corpus. Please avoid presenting associations as proof of supernatural events, population prevalence, or causal psychological mechanisms.

## Pull Request Checklist

- Explain what changed and why.
- Identify any files generated by scripts.
- Include enough detail for another researcher to reproduce the change.
- Keep unrelated local drafts, render caches, and temporary files out of the commit.
- Preserve credit to Taechasith Kangkhuntod as the main creator.
